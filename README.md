# Лабораторна робота № 3. Операції зі структурами даних

## Мета
Поглибити розуміння структур даних в Python (списки, кортежі, словники, множини) та навчитися ефективно виконувати операції з ними для вирішення практичних задач.

## Порядок виконання роботи
1.  Ознайомтеся з теоретичною частиною та прикладом виконання завдання.
2.  Оберіть свій варіант завдання зі списку нижче.
3.  Створіть програму [`src/lab3.py`](src/lab3.py), яка реалізує функціонал відповідно до вашого варіанту. Ви можете використати наданий приклад як основу.
4.  Програма повинна бути інтерактивною, з меню для вибору операцій.
5.  Заповніть звіт у файлі [`REPORT.md`](./REPORT.md), надавши відповідь на контрольне запитання для вашого варіанту та сформулювавши висновки.

## Завдання для всіх варіантів
1.  **Розробити програму для аналізу та обробки даних у вибраній предметній області.**
    *   Оберіть предметну область відповідно до варіанту.
    *   Підготуйте набір даних у вигляді списку словників або інших відповідних структур.
2.  **Реалізація базових операцій зі структурами даних.**
    *   Напишіть функції для додавання, видалення та оновлення елементів у вашій структурі даних.
    *   Реалізуйте функції для пошуку та фільтрації даних.
3.  **Розробка специфічних функцій аналізу.**
    *   Створіть функції для обчислення статистик (наприклад, середнє значення, мінімум, максимум).
    *   Реалізуйте функції для групування та агрегації даних.
4.  **Застосуйте вбудовані функції та методи.**
    *   Використайте функції `map()`, `filter()`, `reduce()` для обробки даних.
    *   Застосуйте методи сортування та зрізи для роботи зі списками.
5.  **Робота з множинами та словниками.**
    *   Реалізуйте операції з множинами (об'єднання, перетин, різниця).
    *   Використайте словники для створення індексів або підрахунку частот.
6.  **Створення інтерактивного інтерфейсу.**
    *   Розробіть меню для вибору різних операцій з даними.
    *   Реалізуйте функції для виведення результатів у зручному форматі.
7.  **Надайте відповідь на контрольне запитання у файлі [`REPORT.md`](./REPORT.md).**
